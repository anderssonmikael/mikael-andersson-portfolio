This is a portfolio website for me, Mikael Andersson, aimed towards webdevelopment.

4 pages total (Home, About, Projects & Contact) with proper semantic according to the w3 validator.

The home page is built using flexbox and the projects page is a proof of concept for a bento-grid built using grid.

Everything is built mobile first with two breakpoints (640px and 1200px).

All the content has been checked for proper contrast using coolors.co contrast checker.

The contact page has a functioning form that is responsive although it does not send any actual data.

Published using GitHub pages.

All links are working and no code goes unused, the image has been converted to a webp and resized to save space.

Images are stored in ./assets and the CSS is stored in ./styles/styles.css.

Zero errors or warnings through https://validator.w3.org/ and https://validator.w3.org/.

https://anderssonmikael.github.io/mikael-andersson-portfolio/

Known issues: About page could use better styling, when I built it at the start I tried using flexbox but it didn't turn out the way I wanted it. I will likely rebuild it with grid in the future and add more styling.
